# SD-CLI-WPF-AMD — исходный код

WPF-приложение на .NET 10 (`net10.0-windows`), которое собирает сложные команды `sd-cli.exe` в простой интерфейс. Есть два режима: генерация фото и генерация видео.

## Состав

| Файл | Назначение |
| --- | --- |
| `MainWindow.xaml` / `.cs` | Окно, стартовый экран выбора режима, интерфейсы фото и видео, drag-drop |
| `ViewModels/MainViewModel.cs` | Состояние, команды, генерация, история, сохранение настроек |
| `ViewModels/RelayCommand.cs` | Реализация `ICommand` |
| `Services/EngineRunner.cs` | Запуск `sd-cli.exe`, аргументы для фото и видео, отмена, лог |
| `Services/SettingsService.cs` | `AppSettings`, чтение/запись `settings.ini` и `history.txt` |
| `Controls/NumericStepper.xaml(.cs)` | Числовой ввод с кнопками |
| `Converters.cs`, `Themes/DarkTheme.xaml` | Конвертеры и тёмная тема |
| `GenerationItem.cs` | Элемент истории, миниатюры |

## Сборка

Нужен Windows и .NET 10 SDK. Перед сборкой положите `sd-cli.exe` и его DLL в папку `engine\` рядом с проектом — их можно взять из `..\Release\engine` этого архива.

```powershell
dotnet build SD-CLI-WPF-AMD.csproj
dotnet publish SD-CLI-WPF-AMD.csproj -c Release -o out
```

`csproj` копирует содержимое `engine\**\*` в выходную папку. Готовый exe после publish лежит в `out\SD-CLI-WPF-AMD.exe`.

## Режимы

### Фото

- Модель `.gguf` / `.safetensors`, опционально LoRA с весом.
- Позитивный и негативный промпты, поле «Поза / детали», шаги, CFG, размер, сид, сэмплинг DPM++ 2M.
- LoRA добавляется в промпт как `<lora:имя:вес>`, папка LoRA передаётся через `--lora-model-dir`.
- Результат — `.png` в выбранной папке.

### Видео

Запуск идёт той же программы, но с `-M vid_gen`. Обязательны только модель и папка сохранения.

| Плашка | Флаг CLI | Обязательно |
| --- | --- | --- |
| Модель · Diffusion | `--diffusion-model` | да |
| Текст енкодер | `--t5xxl` | нет |
| VAE | `--vae` | нет |
| Исходник: начальный кадр | `-i` | нет |
| Исходник: конечный кадр | `--end-img` | нет |
| Исходник: Clip Vision | `--clip_vision` | нет (нужен для I2V/FLF2V) |
| Папка сохранения | `-o` | да |

Дополнительно передаются `--video-frames`, `--fps`, `--preview vae`, `--preview-path`. Результат — `.webm`; в истории и в панели результата показывается последний кадр-превью `*_preview.png`. Движок `vid_gen` не принимает несколько стартовых изображений: поддерживаются только стартовый и конечный кадры.

## Настройки

Всё сохраняется в `settings.ini` рядом с exe: последний режим, оба набора промптов, пути, числовые параметры. Стартовый экран показывается всегда, последний использованный режим подсвечивается; Enter продолжает с него.

`history.txt` хранит пути к последним 30 результатам. Для видео миниатюра берётся из соседнего `_preview.png`, а двойной клик открывает сам видеофайл системной программой.

## Проверка

Автоматических тестов в проекте нет. Минимальная проверка — `dotnet build` без ошибок и запуск `SD-CLI-WPF-AMD.exe`.
