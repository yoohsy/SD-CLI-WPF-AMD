Графический интерфейс на WPF для stable-diffusion.cpp (sd-cli.exe)
с тёмным оформлением в стиле AMD.

Состав архива:
- SD-CLI-WPF-AMD.exe и зависимости;
- папка engine с sd-cli.exe и библиотеками движка;
- настоящий файл описания.

Запуск:
1. Распаковать архив в любую папку.
2. Запустить SD-CLI-WPF-AMD.exe.
3. Выбрать модель (.gguf или .safetensors), при необходимости LoRA,
   указать папку сохранения, ввести промпт и нажать «Сгенерировать».

Требования:
- Windows 10/11 x64;
- Microsoft .NET 10 Desktop Runtime (на этом ПК уже установлен);
- папка engine должна оставаться рядом с исполняемым файлом.

Возможности:
- тёмная тема, красный акцент, карточки и кастомные элементы управления;
- позитивный промпт, негативный промпт и отдельное поле позы;
- шаги, CFG, ширина, высота, seed и режим случайного seed (-1);
- LoRA с настройкой веса и перетаскиванием файлов мышью;
- предпросмотр результата, история генераций и лог выполнения;
- настройки сохраняются в settings.ini, история — в history.txt.

Исходный код: https://github.com/yoohsy/SD-CLI-WPF-AMD
